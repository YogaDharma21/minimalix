# Minimalix

Landing page for Minimalix. Single static page that lists Product Entries inside standard Landing Chrome.

## Language

**Product Entry**:
Static name, description, icon and link rendered in the features grid.
_Avoid_: product, feature, card

**Landing Chrome**:
Navbar, hero CTA, footer and 404 framing around Product Entries.
_Avoid_: helper, helper here and there
